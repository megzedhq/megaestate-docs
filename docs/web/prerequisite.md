# Setup Web Application - Prerequisite

Before deploying the web application (React/Vite frontend), make sure these basics are ready.

---

## Requirements

### 1) Backend/API must be working
- Admin/API backend is fully installed
- API domain is reachable (recommended: HTTPS)
- API is returning data correctly (categories, listings, images)

### 2) Hosting for web app (VPS Recommended)
Use a **VPS** for better speed and smooth updates.

- **Minimum:** 4GB RAM  
- **Recommended:** 8GB RAM

### 3) Domain + SSL ready
- Web domain is ready
- SSL is enabled (HTTPS is recommended)
- API domain SSL is also enabled

### 4) Web build is ready
- You have a working build environment (Node.js + npm) on your PC or VPS
- You know the correct API Base URL for the web app

---

## Buyer Checklist

- [ ] Admin/API backend is installed and reachable
- [ ] Web domain and SSL are ready
- [ ] API Base URL is confirmed and correct
- [ ] VPS selected (Minimum 4GB RAM, recommended 8GB RAM)
- [ ] Web app build environment is available (PC or VPS)
